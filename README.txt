ECOCYCLE - BEGINNER FRIENDLY SDG 12 PROJECT

RUN ON WINDOWS:
1. Extract the ZIP.
2. Open the EcoCycle_Beginner_Project folder in VS Code.
3. Open Terminal > New Terminal.
4. Install Flask: python -m pip install -r requirements.txt
5. Run: python app.py
6. Open: http://127.0.0.1:5000

IMPORTANT: Run python app.py in the folder that contains app.py.
The SQLite database ecocycle.db is created automatically.

FEATURES:
- Home dashboard
- Add and view surplus food
- Mark food as collected
- Record vegetable waste and composting stage
- Waste segregation guide

This is a learning/demo project. It does not provide real-time food collection,
user accounts, or automatic food-safety checks.
